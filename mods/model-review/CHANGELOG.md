## 0.36.0
- 節の順と見出し・文言を統一する（mr-012。D4 節順・D6 見出し・用語、D7 数字表記）。ペインとテキストで同じ見出し・同じ語を使い、判定・計算は変えていない。
  - 節の順（ペイン）: 結論 → タイトル → 金額 → 所見（警告を含む）→ モデル × effort → 高コスト → ループ別 → 切替の見積り → コスト（内訳・推移・advisor・使用率）→ 信頼度 → 用語 → 判定基準。テキストは同じ順で、コストの後に `■ 信頼度` を置く。
  - 金額: ペインはタイトルの直下に `金額` 行を出し、コスト節の行は削った（金額を 2 か所に出さない）。テキストの `金額:` 行と同じ文面（`moneyLineBody`）。区切りは ` · `、差に向きの語（実が大きい・推定が大きい）を付ける。
  - 所見: 見出し `妥当性（参考）· 見直し候補の内訳` → `所見`（テキストは `■ 所見 · ヒューリスティック`）。再構築・TTL 乖離の警告は所見の中、指摘の後に出す（ペインはバッジ、テキストは `【再構築】` などの行）。
  - 信頼度: 末尾の注記を `信頼度` の節にまとめた。切替の注記はペインで `注意` バッジをやめ、信頼度の注記として出す。結論行の `· 注意 N 件` は据え置き（件数の数え方は変えていない）。
  - 用語: コスト節の末尾から、判定基準の直前（最下段）へ移した。差の語は `差（実 − 推定）`。
  - 文言: テキストの `合計推定コスト` → `推定`、`セッション実コスト（読み込み後）` → `実（読み込み後）`、`差（実コスト − 推定）` → `差（実 − 推定）`、指摘なしの行 → `過剰・不足の指摘なし`（ペインとテキストで共通）、内訳の手がかりの `注意欄` → `所見`。
  - 数字（D7）: 判定基準の出力の上限を `1,000 tokens`（桁区切り）にした。金額の小数 4 桁と符号の形（`-$0.0187`）は変えていない。
  - ペインのコスト節は、中身（使用率・内訳・推移・advisor）がないとき見出しごと出さない。テキストのコストの節は従来どおり常に出す。
  - テスト: 表示の文言を固定していたテスト（ペイン・テキスト・register・verdict・pace・sections）の期待値を更新し、節の位置・金額行・所見と信頼度の振り分け・用語行の位置・1,000 を確かめるテストを追加。
